# Cleveland Local Sample

This folder is for a local Cleveland-area sample used for development testing. The actual CSV files are intentionally ignored by git.

The local sample can contain:

- `raw_cleaned_20230401_20230501_cleveland.csv`
- `raw_cleveland-elyria-oh_sensors.csv`
- `raw_cleveland_202204_baseline.csv`
- `observations.csv` using the canonical Diurnalize observation schema
- `baseline_grid.csv` using the canonical Diurnalize baseline schema

For access to a comparable real-data sample, contact `abcnishant007`, or recreate one from publicly available / accessible sources discussed with the paper, such as GHAP-like baseline data and PurpleAir-style sensor observations.
